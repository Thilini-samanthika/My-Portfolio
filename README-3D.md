# 3D Home Upgrade — Thilini Samanthika

This is a copy of the previously uploaded repaired portfolio, upgraded with a lightweight, original React Three Fiber 3D girl-developer Home scene. About, Skills, and Projects remain unchanged.

## Run

1. Open this folder in VS Code.
2. Run `npm install` (internet connection needed to download Three.js packages).
3. Run `npm run dev`.
4. Open the URL Vite prints.

## Integrate with your *latest* local portfolio

If you already added a Contact section to your current local project, **do not replace your whole project with this ZIP**. Instead:

1. Copy `src/components/three/HeroScene.jsx` into your local project.
2. Copy `src/sections/Home.jsx` into your local project.
3. Run `npm install three @react-three/fiber @react-three/drei` in your local project.
4. Keep your current `App.jsx`, `Contact.jsx`, and other sections unchanged.

This uploaded repaired ZIP did not contain `Contact.jsx`, so this copy does not invent or replace your current Contact implementation.

The avatar is constructed from 3D meshes, not a downloadable `.glb` model. A custom modeled avatar can be substituted later.
